# AFC Website

Dit is de website van Amsterdamsche FC. Een voetbalclub uit Amsterdam.

## Wat staat er op de website

- Home pagina met nieuws en evenementen
- Nieuws pagina met alle berichten
- Agenda met wedstrijden en evenementen
- Teams pagina met alle elftallen
- Uitslagen van wedstrijden
- Contact pagina
- Admin gedeelte voor beheerders

## Hoe te gebruiken

1. Zet alle bestanden in je webserver map
2. Maak een database aan met de bestanden in de config map
3. Open index.html in je browser

## Bestanden

- HTML bestanden voor alle pagina's
- style.css voor de opmaak
- js map met JavaScript bestanden
- fotos map met afbeeldingen
- admin map voor het beheer gedeelte
- php map voor de backend

## Database

Gebruik db.sql om de database aan te maken. Daar staan alle tabellen en voorbeeld data in.
